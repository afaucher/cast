# Fonts

All four are under the SIL Open Font License 1.1 (each folder's `OFL.txt`). Downloaded 2026-10-17
from the official Google Fonts repository, https://github.com/google/fonts (`ofl/<family>/`).

| Folder | Family | Used for (carbon-copy form UI) |
|---|---|---|
| `barlow_condensed/` | Barlow Condensed (Medium, SemiBold, Bold, ExtraBold) | printed form labels, headers |
| `courier_prime/` | Courier Prime (Regular, Bold) | typed values |
| `black_ops_one/` | Black Ops One | rubber stamps |
| `caveat/` | Caveat (variable weight) | grease-pencil and handwritten marks |

OFL allows bundling with the game; the license files must ship alongside (they are in the repo) and
the fonts may not be sold on their own.
